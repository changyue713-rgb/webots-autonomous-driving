# ELEC5308 Autonomy Library

A baseline autonomous perception and navigation library developed for ELEC5308 Assignment 1.

## Overview

The library provides reusable modules for autonomous vehicle perception and navigation:

- Lane and driving-area detection
- Object detection
- Object tracking
- Traffic-condition detection
- Semantic segmentation
- Path following
- Steering control
- Speed control

The core modules are designed to be independent of the Webots simulator, while simulator-specific functionality is provided through adapters.
